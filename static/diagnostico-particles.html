🔥 DIAGNÓSTICO DE PARTÍCULAS DE CENIZA

PRUEBA 1: Partículas Inline (No requieren archivos externos)

Esta prueba crea partículas DIRECTAMENTE en el HTML con CSS inline. Si estas funcionan pero las otras no, el problema está en los archivos externos.

PRUEBA 2: Verificar Archivos Externos

Verifica si style.css y ash-particles.js se cargan correctamente.

PRUEBA 3: Sistema de Partículas (Requiere archivos externos)

Cuenta las partículas creadas por ash-particles.js. Si el número es 0, el JavaScript no se ejecutó.

PRUEBA 4: Logs de Console

Abre DevTools (F12) → Console y verifica estos mensajes:

✅ [Emberholm Ash Particles] 40 particles initialized
✅ [Emberholm Ash Particles] 🔴 DEBUG particle created
Presiona F12 para abrir DevTools y ve a la pestaña Console.

PRUEBA 5: Test de Z-Index

Crea una partícula con z-index EXTREMADAMENTE alto para verificar que no esté siendo cubierta por otros elementos.
